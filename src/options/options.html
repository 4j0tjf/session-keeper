Session Keeper 설정

로그인 세션 연장/만료 팝업을 찾아 자동으로 누릅니다. 목록 항목은 한 줄에 하나씩 적고, 한글은 띄어쓰기를 무시하고 비교합니다.

사이트별 직접 지정

자동 인식이 안 되는 사이트는 "호스트 CSS선택자"를 한 줄에 하나씩 적으세요. 해당 요소가 화면에 나타나면 누릅니다. 개발자 도구(F12)에서 연장 버튼을 우클릭 → Copy → Copy selector로 선택자를 얻을 수 있습니다.
