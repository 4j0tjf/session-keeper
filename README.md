# Session Keeper

로그인 세션이 곧 만료된다는 팝업("로그인 시간을 연장하시겠습니까?", "자동 로그아웃까지 남은 시간 …")이 뜨면
**자동으로 '연장'·'확인'을 눌러 주는** Chrome 확장 프로그램입니다. Edge, 네이버 웨일 등 크로미움 기반 브라우저에서도 동작합니다.

## 무엇을 눌러 주나요

| 팝업 형태                                                                             | 동작                                                                                                   |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 페이지 안 레이어/모달 팝업 (`<div class="layer_pop">`, `<dialog>`, `role="dialog"` …) | 세션 안내문 옆의 **연장 버튼**(연장, 로그인 연장, 시간 연장하기, 로그인 유지, Stay signed in …)을 누름 |
| 세션 만료/연장 안내 팝업의 **확인 버튼** (확인, 예, OK …)                             | 팝업 문구에 세션 단어 + 만료/연장 단어가 함께 있을 때만 누름                                           |
| `window.open` 으로 뜨는 작은 팝업창, iframe 안의 팝업                                 | 위와 같은 기준으로 누름                                                                                |
| 브라우저 기본 확인창 `confirm("로그인 시간을 연장하시겠습니까?")`                     | 창을 띄우지 않고 바로 '확인'으로 답함                                                                  |
| 브라우저 기본 알림창 `alert("로그인 시간이 연장되었습니다.")`                         | 창을 띄우지 않고 바로 닫음                                                                             |
| 사이트별로 직접 지정한 CSS 선택자                                                     | 그 요소가 화면에 나타나면 누름                                                                         |

### 누르지 않는 것

- **로그아웃 / 취소 / 닫기 / 연장 안함** 같은 버튼
- 세션과 관계없는 팝업 (예: "계약 기간을 연장하시겠습니까?"의 '연장', "저장되었습니다"의 '확인')
- 세션과 관계없는 확인창 (예: `confirm("정말 삭제하시겠습니까?")`은 그대로 뜸)
- 비밀번호 입력칸이 있는 로그인 화면의 버튼
- 페이지가 열릴 때부터 늘 보이던 버튼 (예: 상단바에 항상 있는 "로그인 연장" 버튼). 팝업으로 **새로 나타난** 버튼만 누릅니다.

같은 팝업은 30초 안에 다시 누르지 않으며, 팝업이 닫혔다가 다음 만료 때 다시 뜨면 또 누릅니다.

## 설치

1. 이 저장소를 내려받습니다. (`git clone` 또는 GitHub의 **Code → Download ZIP** 후 압축 해제)
2. 크롬 주소창에 `chrome://extensions` 입력 (Edge: `edge://extensions`, 웨일: `whale://extensions`)
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 내려받은 폴더(`manifest.json`이 있는 폴더) 선택
5. 설치하면 이미 열려 있던 탭에도 바로 적용됩니다.

### 업데이트

새 버전을 받아 같은 폴더에 덮어쓴 뒤, `chrome://extensions`에서 Session Keeper의 **새로고침(↻)** 버튼을 누릅니다.
열려 있는 탭에도 바로 적용됩니다.

## 사용

툴바의 Session Keeper 아이콘을 누르면:

- **자동 연장 사용**: 전체 켜기/끄기
- **이 사이트에서 사용**: 지금 보고 있는 사이트만 끄기/켜기
- **최근 자동 처리**: 언제, 어느 사이트에서, 무엇을 눌렀는지 기록 (최근 50건)

오른쪽 위 상태가 **작동 중**이면 지금 탭에서 동작하고 있는 것입니다. **새로고침 필요**가 보이면 알림의
**새로고침** 버튼을 누르세요 (확장 프로그램을 껐다 켠 경우 등).

### 자동으로 안 눌릴 때 – 사이트별 직접 지정

1. 세션 연장 팝업이 떠 있을 때 연장 버튼을 우클릭 → **검사**
2. 개발자 도구에서 선택된 요소를 우클릭 → **Copy → Copy selector**
3. 확장 프로그램 **설정 → 사이트별 직접 지정**에 `호스트 선택자` 형식으로 한 줄 추가

```
intranet.example.com #btnSessionExtend
erp.example.co.kr .layer_session a.btn_extend
```

호스트는 하위 도메인까지 포함합니다 (`example.com` → `www.example.com`도 해당).

설정의 **판별 단어 (고급)** 에서 세션 단어, 연장 버튼 문구, 누르지 않을 문구 등을 사이트 사정에 맞게 고칠 수 있습니다.

### 브라우저 기본 알림창(alert)이 그대로 떴을 때

`"사이트주소 내용:"` 제목의 회색 창은 브라우저 기본 알림창입니다. 버튼이 아니라서 사이트별 선택자로는 처리하지 않고,
문구로 판단합니다 (세션 단어 + 만료/종료/연장 단어). 그대로 떴다면:

1. 툴바 아이콘의 상태가 **작동 중**인지 확인합니다. (**새로고침 필요**면 새로고침)
2. 설정의 **브라우저 기본 대화상자(alert / confirm)도 처리**가 켜져 있는지 확인합니다.
3. 문구에 세션 단어나 만료 단어가 없으면 설정의 **판별 단어 (고급)** 에 추가합니다.

예: 메이플 옥션의 `다른 환경에서 접속이 감지되어 현재 세션이 종료되었습니다.`는 기본 설정으로 닫힙니다 (`세션` + `종료`).
다만 이 알림은 다른 곳에서 같은 계정으로 접속해서 **이미 세션이 끊긴 뒤** 뜨는 것이라, 닫아도 로그인 상태가 돌아오지는 않습니다.

## 한계

- 브라우저 탭이 열려 있어야 합니다. 브라우저를 닫거나 PC가 절전 모드에 들어가면 동작하지 않습니다.
- 이미 만료된 세션을 되살리지는 못합니다. 만료 **전에** 뜨는 연장 팝업을 눌러 주는 것입니다.
- 사이트가 alert/confirm 대신 자체 팝업을 쓰면 DOM 팝업 규칙으로 처리합니다. Shadow DOM 안의 버튼은 찾지 못합니다.
- 회사·기관 보안 정책상 자동 세션 연장이 허용되는지 확인하고 사용하세요.

## 동작 방식

- `src/content/content.js` (콘텐츠 스크립트): `MutationObserver`와 2초 주기 검사로 새로 보이게 된 버튼을 찾고,
  버튼 문구와 주변 팝업 문구로 세션 연장 팝업인지 판단합니다.
- `src/content/page-hook.js` (페이지 문맥, `world: "MAIN"`): `window.alert`/`window.confirm`을 감싸고,
  호출될 때마다 content.js에 동기 이벤트로 물어 자동으로 답할지 정합니다. 버튼 클릭도 여기서 실행해
  `href="javascript:…"` 링크가 확장 프로그램 CSP에 막히지 않게 합니다.
- `src/shared/rules.js`: 기본 단어 목록과 판별 로직 (브라우저 API 없는 순수 함수)
- `src/popup/`, `src/options/`: 툴바 팝업과 설정 화면

## 개발

```sh
npm install
npm test          # 판별 로직 단위 테스트 + 실제 Chromium에 확장 프로그램을 올린 E2E 테스트
npm run icons     # icons/icon.svg → PNG 다시 만들기
npm run zip       # 배포용 session-keeper.zip 만들기
```

E2E 테스트는 `test/fixtures/`의 예제 페이지(레이어 팝업, javascript: 링크, iframe, 팝업창, 반복해서 뜨는 팝업,
세션과 무관한 팝업 등)를 띄워 확인합니다. Playwright용 Chromium이 없다면 `npx playwright install chromium`을 먼저 실행하세요.
